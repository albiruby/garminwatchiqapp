## Gaya Visual UI yang terlihat
- Menu: teks putih + sub-teks abu-abu, ikon kecil berwarna — konsisten total
- Data field: **label kecil putih di atas + angka raksasa putih**; field kecil berpasangan 2 kolom
- Training Readiness: **gauge setengah lingkaran + angka hero + label status** — pola terbaik untuk indikator status
- Race result: nama event + waktu aktual vs goal + grafik mini — pola "aktual vs target" yang sama dengan ahead/behind kita
- Watchface: jarum analog + angka digital hijau raksasa — contoh pemakaian warna berani

## Relevan untuk RacePilot (paling penting — device sekelas FR165)
- `03/04` (eight/four fields) = referensi langsung pembagian ruang layar 390×390 untuk data field
- `05-midrun` = bukti pola timer + jarak + pace + HR muat dalam satu layar lari
- `06-race-result` = pola "aktual vs goal" untuk layar finish kita
- `08` gauge = kandidat pola untuk confidence / status target
