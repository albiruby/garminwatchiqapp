## Gaya Visual UI
- Watchface hibrida: ring menit analog (skala 05–60) + angka digital raksasa di tengah
- Jam "19" oranye AMOLED, menit "36" putih — dua warna, hierarki jelas
- Widget kecil di sisi: ikon moon, "8:10 h", "Mon", "25.6" — abu-abu, tidak bersaing dengan angka hero
- Background hitam pekat, bezel gelap, strap lime sebagai satu-satunya warna cerah di hardware

## Tipografi
- Angka: sans-serif geometris ekstra-tebal, tabular
- Label: kecil, abu-abu, uppercase longgar
- Web: headline tebal, body kecil regular

## Warna
- BG `#000000`, teks putih `#FFFFFF`, sekunder abu-abu
- Aksen: oranye AMOLED (~`#FF7A1A`) — hanya untuk elemen primer (jam)
- Hardware lime (`#C6E500`-ish) tidak masuk ke UI layar

## Relevan untuk RacePilot
- Pola "satu angka hero + label kecil" = sama dengan pendekatan kita
- Aksen tunggal per layar; jangan campur teal+hijau+merah sekaligus kecuali delta
- Marathon Time mereka = konsep setara Projected Finish kita
