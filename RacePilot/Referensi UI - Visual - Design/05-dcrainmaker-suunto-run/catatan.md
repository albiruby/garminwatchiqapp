## Gaya Visual UI yang terlihat
- Menu/teks putih di atas hitam, aksen kuning khas Suunto untuk tombol/aksi primer ("START")
- Layar interval: blok warna (kuning untuk Interval, merah muda untuk Recover) + panah progres — pola "blok status berwarna" yang bagus untuk status ahead/behind kita
- Kontrol musik: ikon besar, judul di tengah, progress bar tipis — minimal dan terbaca
- Font jam: sans-serif medium, tidak terlalu tebal; label kecil abu-abu

## Relevan untuk RacePilot
- Pola blok warna untuk status (kuning/merah) bisa dipakai untuk badge status RACING/FINISHING
- Layar interval mereka (jarak + pace + reps) mirip kebutuhan lap counter Track mode kita
- Tombol aksi kuning full-width ("START") = pola CTA yang jelas
