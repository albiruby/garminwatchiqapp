# Frame Video Review — Suunto Run (layar jam asli)

Sumber: DC Rainmaker review + video (https://www.dcrainmaker.com/2025/05/suunto-run-in-depth-review.html)

## File (hanya yang menampilkan UI jam)
- `01-breathe-widget.png` — widget Breathe (animasi bunga + timer)
- `02-routes-menu.png` — menu Routes (daftar rute + jarak, ikon biru, panah >)
- `03-track-running-data.jpg` — **layar data Track Running saat lari: 1:00'52, AVG PACE 5'38/km, 10.80 km** (acuan terbaik)

## Gaya Visual UI yang terlihat
- Menu list: teks putih + sub-teks abu-abu + chevron `>`, ikon lingkaran berwarna di kiri
- Layar data lari: timer raksasa putih di atas, AVG PACE + jarak di bawah dengan label kecil — hierarki persis pola kita (waktu → pace → jarak)
- Format pace Suunto: `5'38/km` (kutip satu), bukan `:` — jangan ditiru, kita ikut konvensi Garmin
- Widget Breathe: satu visual fokus (bunga) + timer — contoh "satu layar satu tugas"

## Relevan untuk RacePilot
- `03-track-running-data.jpg` = bukti pola timer-besar + pace + jarak bekerja di layar kecil saat bergerak
- Menu Routes (ikon + 2 baris teks + chevron) = pola daftar yang bisa dipakai untuk layar pilih preset bila dibutuhkan
