## Gaya Visual UI yang terlihat

- Watchface: angka besar dua-warna (putih + hijau) + tanggal kecil + ikon status
- Bezel berwarna (teal) sebagai identitas varian — hardware, bukan UI

## Relevan untuk RacePilot
- `01-run-data-screen` = komposisi layar lari Garmin standar yang harus kita selaraskan (timer dominan)
- Watchface dua-warna = contoh aman memakai 2 warna angka (putih + aksen)
- FR170 memakai OS sama dengan FR570/FR970 → pola UI ini adalah arah desain Garmin saat ini
