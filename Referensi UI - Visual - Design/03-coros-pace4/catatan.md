# COROS Pace 4 — Catatan Desain

Sumber: https://coros.com/pace4

## File
- `01-hero.png` — hero (ultralight 32 g, AMOLED 1.2")
- `02-page.png` — full page (training tools, race predictor, virtual pacer)
- `03-race-predictor.png` — aset fitur Race Predictor

## Gaya Visual UI
- Lebih padat dari Suunto: satu layar bisa memuat HR + zone bar + pace + distance
- Unit menempel pada angka (`5:18/km` satu baris) — sama seperti pola kita
- Web: banner full-bleed gelap + foto lifestyle + headline condensed tebal

## Tipografi
- Web: grotesque bold condensed untuk headline, body sans netral
- Jam: angka besar medium-weight (tidak setebal Suunto), label kecil abu-abu

## Warna
- BG hitam, putih, abu-abu sekunder
- Aksen fungsional: hijau = on-target, merah = warning
- Virtual Pacer & Race Predictor = fitur setara Need Pace + Projected Finish kita

## Relevan untuk RacePilot
- Validasi pola `nilai + unit sebaris` dan semantik hijau/merah
- "Pace Strategy" (split-by-split race plan) = ide untuk split strategy v2.3
- Struktur halaman (hero → angka spesifikasi → fitur → perbandingan) bisa jadi template Store listing kita
