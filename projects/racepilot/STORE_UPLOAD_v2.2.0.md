## Description

```
RacePilot is a race pacing data field built to answer the four questions that matter most when chasing a finish time:

• How fast am I running? → Lap Pace
• If I keep this effort, when will I finish? → Projected Finish
• Am I ahead or behind my goal? → Ahead / Behind
• What pace do I need from here? → Need Pace

Pick a target (46 race presets from 5K to Marathon, or your own distance and time) and RacePilot does the math live, every second.

CHOOSE YOUR LAYOUT
• Standard (HUD) — big Projected Finish with a progress ring that fills as you close in on your race distance
• Delta — giant +/- time vs your target with a color status bar
• Grid — classic split view: Lap Pace, Need Pace, distance and time
• Focus — big pace with distance and time on one line

THREE RUN MODES
Outdoor Run (GPS), Track Run and Treadmill Run — each with its own pacing engine. Auto Detect picks the right one for you.
• Outdoor: GPS spike rejection, corner protection, tunnel hold and GPS recovery
• Track: pace per lap (200/250/300/400/500 m) with lap counter
• Treadmill: 3-phase warm-up for accurate pace from the first step, plus calibration (x100)

FEATURES
• Real-time Lap Pace, smoothed and stable
• Projected Finish that reacts to real pace changes but doesn't jitter
• Ahead / Behind indicator with color status
• Dynamic Need Pace
• 46 built-in race presets (5K, 10K, Half Marathon, Marathon) plus Custom
• Metric / Imperial units (Auto follows your watch)
• Dark or High Contrast theme and 5 accent colors
• Off-target vibration alert when you fall behind (can be turned off)
• Projected Finish, Ahead/Behind and Need Pace saved to your activity — see the charts in Garmin Connect
• Adaptive pace filtering and confidence scoring to suppress unreliable data
• Auto-pause aware, finish lock after you cross the line
• Responsive layout for round, square and rectangular screens — watches and Edge

HOW TO SET UP
1. Install RacePilot and open Settings in the Connect IQ app.
2. Choose a Race Preset (or Custom distance + time).
3. Pick Run Type (Auto Detect works for most runs) and your Layout.
4. On the watch, add RacePilot as a 1-field data screen in your Run activity.

Works on Forerunner, Fenix, Epix, Enduro, Venu, Vivoactive, Instinct AMOLED, MARQ, D2, Approach and Edge devices.

No account, no network, no data collection — everything stays on your device.
```

## What's New

```
Version 2.2.0 — new look, new layouts, and important accuracy fixes.

New
• Redesigned display: clean HUD with a distance progress ring and Projected Finish as the hero number
• Two new layouts: Delta (big +/- vs target with status bar) and Grid (classic split view)
• Metric / Imperial units setting (Auto follows your watch)
• Dark or High Contrast theme and 5 accent colors
• Projected Finish, Ahead/Behind and Need Pace are now recorded to your activity and shown as charts in Garmin Connect

Fixed
• Projected Finish could stop updating mid-race after a stable stretch — it now follows real pace changes
• Auto Detect could switch an outdoor run to treadmill mode when GPS dropped (tunnels, tall buildings), causing distance jumps — fixed
• Removed hill compensation that did not work as intended and could skew the projection

Improved
• Smarter off-target alert: vibrates when you fall behind, then reminds at most every 2 minutes (was every 30 seconds)
• Larger, clearer ahead/behind indicator on big screens
• 20 automated tests; clean build with zero code warnings

Note: this version adds the "FIT Contributor" permission so RacePilot can save its metrics to your activity file.
```
